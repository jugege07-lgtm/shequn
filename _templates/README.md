# 📦 项目模板

> 每个新项目都从这里开始。复制 `project-template/` 到 `../projects/<project-name>/` 即可启动。

## 使用方法

```bash
# 1. 复制模板
cp -r project-template ../projects/my-new-project

# 2. 重命名 README 中的项目描述
# 3. 开始填写需求和技术栈
# 4. 进入开发
```

## 模板文件说明

| 文件 | 用途 | 首次填写时机 |
|------|------|-------------|
| `README.md` | 项目概述 | 启动时 |
| `REQUIREMENTS.md` | 需求清单 | 启动时 |
| `TECH_STACK.md` | 技术选型 | 启动时 |
| `DEV_LOG.md` | 开发记录 | 开发中每日更新 |
| `KNOWN_ISSUES.md` | 已知问题 | 发现问题时 |
| `PROJECT_SOP.md` | 项目特定流程 | 发现特有模式时 |
| `RETROSPECTIVE.md` | 复盘 | 阶段完成时 |
